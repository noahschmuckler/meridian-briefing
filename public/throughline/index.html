Install Throughline

Throughline runs locally on your own device. This sets it up in a few minutes — no GitHub, no typing file paths.

Current version: latest

1 Download the installer

One small file. Your browser may warn about it — that's expected; it's a setup script.

⤓ Download installer

2 Open PowerShell

Press ⊞ Start, type PowerShell, and press Enter. A blue window opens.

3 Paste this one line and press Enter

It tidies up the downloaded file and runs the installer. (Windows hides the .txt on the download — this handles the rename for you.)

$d="$env:USERPROFILE\throughline-deploy"; New-Item -ItemType Directory -Force $d | Out-Null; Move-Item -Force "$env:USERPROFILE\Downloads\install-throughline.ps1.txt" "$d\install-throughline.ps1"; Unblock-File "$d\install-throughline.ps1"; powershell -ExecutionPolicy Bypass -File "$d\install-throughline.ps1"

4 Pick your shared folder

A browser tab opens to a setup screen. Choose your shared OneDrive folder (under OneDrive - …) — the one shared with your dyad partner. That's it. Throughline only reads those files; it never changes them.

Updating later: come back here, download again, and re-run the same one line. It updates in place and keeps your settings.  ·  Need Node? Install it once from the company app store first.
